# iperf3 节点组示例
# 每行一个服务端，支持 host、host:port 和 [IPv6]:port。
# 每行必须追加 auth=owned 或 auth=authorized，声明该节点为自有或已授权使用。
# 服务端后可追加 name=、region=、provider= 元数据，用于报告展示和排查。
# 空行和 # 注释会被忽略；行尾注释也会被忽略。
#
# 下方使用 RFC 5737 / RFC 3849 文档保留地址，只能作为格式示例，不能直接运行。
# 请替换为你自己可访问、已授权使用的 iperf3 服务端。
# 程序不会内置公共 iperf3 节点，避免依赖不稳定或未授权的公共服务。

192.0.2.10:5201 auth=owned name=Tokyo region=JP provider=SelfHosted
[2001:db8::1]:5201 auth=authorized name=Frankfurt-v6 region=DE provider=Lab
iperf3.example.invalid:5201 auth=authorized name=LosAngeles region=US provider=Example
